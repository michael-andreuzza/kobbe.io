## Where Cloudflare Web Analytics is the better pick

- Your site is already on Cloudflare and you only need to know how busy and how fast it is.
- You want performance data from real visitors with nothing extra to pay for.

## Where Kobbe is the better pick

- You want to track sign-ups, purchases and other events, and see where visitors drop off.
- You want to see which campaigns and UTM tags bring traffic and revenue.
- You want three years of history instead of six months.

## Switching from Cloudflare Web Analytics

Add the Kobbe script and keep Cloudflare Web Analytics running as long as you like, they don't conflict. See [Installation guides](/docs/installation-guides).

Import the last six months of Cloudflare Web Analytics with an API token. Kobbe only fills the days before your first Kobbe pageview, so nothing gets overwritten. See [Import from Cloudflare Web Analytics](/docs/import-from-cloudflare-web-analytics).
