Publish an optional **public maker profile** when you want one link that shows your Kobbe stats without giving dashboard access.

Your profile lives at `app.kobbe.io/@/your-handle` and is read-only for visitors.

## How to enable

1. Open **Account** in Kobbe.
2. Find **Public profile** under account settings.
3. Turn the profile on.
4. Choose your handle. It cannot be changed later.
5. Add an optional display name, pick which sites to include, and choose the stats date range.
6. Save.

Only workspace owners can publish a profile.

## What visitors see

| Section | What it includes |
| ------- | ---------------- |
| **Header** | Profile photo, display name or handle, and how long you have been on Kobbe. |
| **KPI strip** | Visitors, visits, views, bounce rate, session time, and revenue when enabled. |
| **Activity** | A 365-day pageview heatmap across the selected sites. |
| **Traffic chart** | Visitors or revenue over your chosen stats range. |
| **Sites table** | Ranked stats for each site you include on the profile. |

The activity heatmap always covers the last 365 days. KPIs, the chart, and the sites table follow the **Stats range** you pick in settings.

## Profile settings

| Setting | What it does |
| ------- | ------------ |
| **Handle** | Your public URL slug at `app.kobbe.io/@/handle`. |
| **Display name** | Optional name shown at the top of the profile. Leave blank to show your handle only. |
| **Sites** | Choose which workspace sites roll up into the profile stats and table. |
| **Stats range** | Date range for KPIs, the traffic chart, and the sites table. |
| **Show revenue** | Include revenue in KPIs and the sites table when advanced features are enabled. |
| **Shareable dashboards** | Link to a site public dashboard when that site has an active share link. |

## Privacy

Public profiles are optional and off by default. When disabled, your profile URL returns not found.

Profile photos use the same image you upload for your Kobbe account. Revenue and share-dashboard links only appear when you turn those toggles on.

For single-site read-only dashboards, use [Shared dashboards](/docs/shared-dashboards). For iframe cards on your marketing site, use [Embed widgets](/docs/embed-widgets).
